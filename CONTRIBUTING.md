# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a focused branch.
3. Keep security-sensitive decisions server-side.
4. Build the NUI when changing `web/src`.
5. Do not commit generated `web/dist` output; CI verifies the build from source.
6. Test on a development server before opening a pull request.
7. Describe behavior changes and migration requirements clearly.

Please do not include server credentials, private player identifiers, database dumps or personal information in issues, logs, commits or pull requests.
